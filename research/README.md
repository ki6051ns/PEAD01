# PEAD01｜研究全体の総括と資料索引

[リポジトリの入口](../README.md)

決算情報が段階的に価格へ織り込まれるという仮説を、日本株の決算イベントで検証した。Phase 1〜5でデータ・売買・執行の基礎を整備し、Phase 6で日足に統一した条件選択、Phase 7でその頑健性を評価した。旧Phase 6・6.1の数値、図表、方法論は[アーカイブ](../archive/legacy_phase6/README.md)に収録している。

| Phase・目的 | 使用データ・WF期間 | 主な結果 | 残課題 |
| --- | --- | --- | --- |
| [Phase 1](phase1_to_phase5_summary.md#phase-1データと初回集計) · イベント整備 | 2021-11-15〜2026-11-13の決算・価格。記述分析 | 75,369件。Day 5追加TOPIX超過は平均−0.28% | イベント時刻、評価起点、欠損の扱い |
| [Phase 2](phase1_to_phase5_summary.md#phase-2年限と対照比較) · 初動と追加反応 | Phase 1の決算・価格、同日・同業種等の対照。記述分析 | 起点を翌営業日始値に揃え、初動符号別の追加反応を比較 | 対照選定と観測上の超過収益を執行可能なシグナルへ結び付ける |
| [Phase 3](phase1_to_phase5_summary.md#phase-3ポートフォリオと執行) · 絶対収益 | 日足、執行検証用分足。動的WFは2024〜2026年の各評価区間 | 固定20営業日ロングは年率6.16%、Sharpe 0.62、最大DD −17.70%（固定評価1,221日） | 約定可能性、ショート制約、独立OOS |
| [Phase 4](phase1_to_phase5_summary.md#phase-4分足の価格発見) · 分足価格発見 | 2024-11-01〜2026-11-13の分足。記述分析 | 初回約定31,986件、5〜120分で市場代理調整値が揃う7,692件 | 時刻・比較集合・市場代理への感応度 |
| [Phase 5](phase1_to_phase5_summary.md#phase-5条件付き反応と費用) · 条件と費用 | Phase 4の分足、業種・流動性等。条件別分析 | 高ADVのTOPIXロングで1分遅延・10bpは1件平均+0.05%、20bpでは−0.05% | 費用・遅延、取引容量、独立OOS |
| [Phase 6](phase6_daily_rebuild_summary.md) · 日足で条件選択 | 2021年11月〜2026年11月の日足。WFは2024-10-01〜2026-11-13の516営業日 | 864候補。Neighborの観測最高WF Sharpe 2.00、年率+8.71%、最大DD −2.44% | 四半期・設定への依存、未観測期間 |
| [Phase 7](phase7_summary.md) · 頑健性 | Phase 6と同一の516営業日を基準に126・252・504日窓を比較 | 156方式の初動・保有期間・暦期間・イベント寄与を分解。2025Q2を除くとNeighborのSharpeは0.75。 | 収益集中、採用条件の入れ替わり、独立OOS |

Phase 6の観測最高値は成績比較後に特定した値。各WF期の選択は学習と内部検証に基づく。Phase 7の重複窓は記述比較で、独立標本として扱っていない。
