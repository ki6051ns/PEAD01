# PEAD01｜探索パラメータの日本語解説

Phase 6の探索条件とPhase 6.1の資金配分条件を、**「何を変えるのか」「値をどう読むのか」**の観点でまとめています。設定ファイルは [phase6.json](../phase6.json)、実装は [phase6_grid.py](../src/pead01/phase6_grid.py) と [phase61.py](../src/pead01/phase61.py) です。

## Phase 6｜どの決算銘柄をいつ売買するか

| 分類 | パラメータ | 日本語での意味 | 実際に比較した設定例 |
| --- | --- | --- | --- |
| 銘柄選択 | 初動騰落率の閾値（`strength`） | 決算発表後の初動が**何%以上動いた銘柄**を対象にするか | **0%、1%、3%、7%** |
| 銘柄選択 | 流動性（`adv`） | 過去の売買代金が十分にある銘柄だけを選ぶか | **制限なし、1億円以上、10億円以上** |
| 銘柄選択 | TOPIX所属（`universe`） | 市場全体・TOPIX採用・TOPIX非採用のどこを対象にするか | **全銘柄、TOPIX採用、非採用** |
| 売買方向 | ロング／ショート（`direction`） | 初動上昇後の買い、初動下落後の売り、初動と同方向・逆方向を比較 | **買いのみ、売りのみ、初動追随、初動逆張り** |
| エントリー | 売買・シグナル時刻（`method`） | 決算後の初動を**いつ確認し、最初にいつ注文可能になるか** | 日足の翌営業日寄り、引け前観測、分足の5・15・30・60分後の観測など |
| 保有期間 | ホライゾン（`daily_holds` / `minute_holds`） | エントリー後**どれだけ保有して決済するか** | 日足：**1・2・3・5・10・15・20・30・40・60・90・120営業日**、分足：**5・15・30・60・120分**、引け |
| 決済 | Exit条件（`exit_rule`） | 所定期間以外に、途中で損切りや利益確保を行うか | **期間固定、損切り、トレーリング、失速、反転** |
| 条件分岐 | 銘柄属性・決算情報（`condition`） | 特定の業種、企業規模、業績修正、出来高や市場局面に限定するか | 業種、時価総額、会社予想修正、EPS、市場トレンド・変動率、決算発表時間帯など |
| 個別配分 | 銘柄ごとの重み（`sizing`） | 選んだ銘柄を同じ金額で買うか、初動の強さや変動率で金額を変えるか | **均等、初動強度、逆ボラティリティ** |
| 指数ヘッジ | 市場β調整（`hedge`） | 個別株以外の市場変動要因をTOPIXの損益近似で打ち消すか | **あり／なし** |

**具体例（説明用であり最良条件ではありません）：**「決算後の初動が+3%以上、TOPIX採用かつ過去売買代金1億円以上の銘柄を翌営業日寄りに買い、20営業日保有する」。初動がマイナスのときの逆張りや、5分後の値動きを見て入る条件も探索対象です。

一度にすべての値の直積を評価したわけではありません。業績・業種などの細分化条件や特殊な出口条件は、限られた期間・方向に絞って比較しています。

## Phase 6｜過去のどの戦略を採用するか

これは**個別銘柄の売買条件**とは別の、戦略選択・アンサンブルのパラメータです。

| 分類 | 日本語での意味 | 比較した設定 |
| --- | --- | --- |
| Single（単独最良条件） | 過去の成績が最も良い一つの売買ルールを選ぶ | 単独採用 |
| Top-K（上位K条件） | 成績上位の複数ルールを組み合わせる | **上位3・5・10・20・50条件** |
| Neighbor（近傍条件） | 最良ルールの近くの閾値・期間などもまとめて使う | 近傍パラメータの組み合わせ |
| Shrink（共分散縮小） | 複数戦略の相関の推定誤差を抑え、配分を調整する | 共分散行列の対角50%縮小 |
| Dynamic（動的選択） | 古い相場に合わせた条件を固定せず、一定間隔で選び直す | 過去**126・252・504営業日**または拡張窓（`0`）、**週次・月次・四半期**更新 |

**WF（ウォークフォワード）**は過去の学習期間で条件を選び、その次の期間で検証する方式です。現時点で報告したWFは研究中に既に観察した期間であり、独立した未観測OOSではありません。

## Phase 6.1｜投下資金をどう管理するか

Phase 6の保存済み売買条件を使い、**新しい売買シグナル探索は行わずに**資金配分と信用制約を再評価します。

| パラメータ | 意味 | 探索値 |
| --- | --- | --- |
| 資本配分倍率（`multiplier`） | 1銘柄当たりの基本発注金額を何倍にするか。基準の100万円枠を拡大 | **1・2・3・5・10倍** |
| 信用レバレッジ上限（`leverage`） | 純資産に対する総建玉の上限 | **1・1.5・2・2.5・3倍** |
| 目標稼働率（`target`） | 過去の稼働率を参考に注文量を**縮小するための上限調整** | **5・10・20・30・50%** |
| 保証金・維持率 | 信用建玉を維持するための余力管理 | 原則**委託保証金30%・維持率20%** |
| 金利・売買コスト | 調達・貸株・売買費用の影響 | 通常：信用買い**年2.8%**、貸株**年1%**。金利なし・ストレス・現物限定も比較 |

Phase 6.1の探索格子は **5種類の配分倍率 × 5種類の信用上限 × 5種類の目標稼働率＝125通り**を各方式で比較するものです。903ケースは、複数方式、固定グリッド、選択型WF、費用シナリオなどを合わせた総評価数です。

**目標稼働率5%は常に資産の5%を買うという意味ではありません。** シグナルがなければ発注しませんし、銘柄別容量・信用枠・既存ポジションによって実際の稼働率は変わります。

## 補足｜共通の資金台帳

初期資本は**1億円**。決算シグナルは別々の日に到来し保有期間も重なるため、資金を独立に使い回しません。新規注文は時刻順に、既存建玉・保証金・銘柄容量を踏まえて縮小または見送り。同じ銘柄を保有している間の追加シグナルは見送りします。
