# Phase 6.1

Phase 6の選択履歴と価格経路から選択済みIDだけを再生する。開始時に元の台帳で保存済みWF損益と突合し、差があれば停止する。各配分候補の円建ての日次Parquetを原子的に保存し、同じ入力で再起動すると完了済み候補を再利用する。Phase 6の候補探索は呼び出さない。

制約モデルは現金担保30%、維持率20%、同時グロス上限1〜3倍。銘柄上限は100万円の指定倍率、容量はPhase 6の保存済み事前ADV上限。約定価格・数量はモデル値。同時かつ同一銘柄の需要を相殺し、その方向で最大需要の出口を採用する。既存保有中の重複注文をスキップ。維持率割れを翌営業日に検知した場合は新規停止とし、既存建玉は元の約定可能出口で縮小する。強制成行の約定は仮定しない。日中の建玉評価は観測できる入口・出口・終値まで。[JPX 委託保証金](https://www.jpx.co.jp/glossary/a/15.html) · [維持率](https://www.jpx.co.jp/glossary/a/16.html)

通常は信用買い年2.8%、貸株年1%、売買費用はPhase 6と同じ。信用買いの全額に翌営業日までの暦日分を課す。日計り信用金利はゼロと仮定。信用金利なし、費用1.5倍・金利5%・貸株3%、現物ロングの感応度を計算。ヘッジはPhase 6の指数損益近似で、証拠金はグロスに含める。実際の約定可能枚数、証券会社の維持率、逆日歩、信用規制の全履歴は未確認。

任意の規制CSVは `code,effective,until,known,initial_margin`。日付はYYYY-MM-DD、銘柄は保存された5桁コード。known翌日から適用し、1.0を新規信用停止として扱う。CSVを省略した結果は個別規制未反映。

各ルールと複合の均等・逆ボラ・共分散縮小を別々に報告。配分と目標は過去稼働率を使う上限調整。達成のための注文追加は行わない。四半期選択は最大保有・再試行を考慮して124営業日空けた過去の日次損益で行う。学習不足時は1倍を使用。複合重みも同じ過去窓による。固定全格子は診断用、選択済みポリシーとは区別する。全期間は観測済みWF。パレート判定は評価種別・費用シナリオ内でSharpe・年率・最大DD・平均観測ピーク稼働率の4軸。年率1%未満のフラグを併記する。
