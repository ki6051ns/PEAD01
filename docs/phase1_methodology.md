# Phase 1B〜1E 方法と品質検証

## イベントと時点

- `event_id` は J-Quants の5桁証券コードと開示番号で固定。短信は1開示1行で、同日複数・同会計期間の再開示も保存する。訂正専用フラグがないため、同じ期間・連結区分・会計基準の再開示を候補とし、同日複数短信とともに基礎集計から外す。原文未照合のため確定訂正件数は分からない。
- 開示時刻はTDnet由来の JST 分精度。時刻欠損を維持し、分足から除く。年初の財務比較には取得期間の左端による欠損が出る。
- 対象は日付付き銘柄マスタの東証普通株。属性・時価総額・株価・売買代金は開示日前の直近東証営業日。新規上場時は開示日マスタで対象適格性だけ判定できる。現行銘柄一覧で過去の母集団を絞らない。上場廃止後は価格欠損。コード間の価格・財務連結は未実装で、コード変更をまたぐ比較は欠損し得る。企業再編・コード再利用の経済的同一性は個別確認が必要。
- 増減益は、前年同期間かつ同じ連結区分・会計基準の営業利益との差。会社予想比は FY・2Q の実績と同じ決算年度末を対象とする直近の事前会社予想との差を予想絶対値で割る。2Qは半期累計。会社予想修正は短信内の通期予想（FY短信は翌年度予想）を同ターゲットの直前予想と比較。ゼロ分母や同日競合する事前値は欠損とする。予想公表と実績の間で株式調整単位が変わったEPS比較は除外する。市場コンセンサスは入っていない。
- 日時の順序が同日内で確定できない事例にも同じ判定を適用できるよう、事前予想・前年値の利用を常に開示日の前日までに制限する。パイプラインで事前情報の日付を検査する。J-Quants の財務行が当時のAPIで利用できた時刻には公表から遅延があり得る。

## 日次

取引日をJPXカレンダーで数える。東証前場は09:00〜11:30、後場は12:30から2024年11月1日までは15:00、2024年11月5日以降は15:30まで。制度改定後は15:25から注文受付のみ、15:30に板寄せ。発表が引けと同じ分の場合は当日の終値を事前価格に使わない。[JPX 取引時間延伸](https://www.jpx.co.jp/corporate/news/monthly-headline/202411.html)

- **総反応**は原則前営業日終値から観測点まで。引けより厳密に後の開示は当日終値を基準にする。日中開示の前営業日終値には発表前の日中値動きが混ざる。
- **追加反応**は、寄り前発表なら当日始値、その他は開示日より後の最初の営業日始値から。日中の直後反応は分足で観測する。
- **時間軸**は開示日の翌営業日始値、および開示後に引けがある最初の営業日から数えて1・3・5・10・20日目の終値。引け同時・引け後・時刻欠損は翌営業日が Day 1。日中開示では Day 1 の終値が日次追加反応の基準時刻より早く、当該リターンは欠損。
- **超過**は同じ取引日と始値・終値の組み合わせの株価リターンからTOPIX価格リターンを引いた値。
- 分割・併合・一部権利落ちは、区間内の権利落ち日に付与される係数だけで始点と終点を同じ単位にする。現金配当は加えず、配当落ちは価格に残る。上場廃止の精算価格・対価は含まない。[J-Quants 価格調整仕様](https://jpx-jquants.com/ja/spec/eq-bars-daily/adj)
- 価格には出来高が正で整合したOHLCを要求し、無約定や欠落を前値で補完しない。ストップ高安フラグを保存する。日足始値が何時に成立したか、値幅制限状態と約定可否の詳細は日足から判定できない。

## 分足

立会内、出来高正、始値・終値正の開始時刻付き約定足のみ。発表と同じ分は除外する。取引可能な最初のセッションで最初に観測したバーの始値を追加反応の基準とする。寄り遅延や無約定で分足がない場合は実際の最初の足まで待つ。セッションに取引がなければ欠損。発表前5分以内の終了済み足、昼休みの前引け、または寄り前・引け後の既知の日足終値を総反応の基準とする。休場をまたぐ場合は価格単位を合わせる。

5・15・30・60分は最初の足からの経過時計分で、直前に完了する足または該当時刻の板寄せ足を用いる。昼休みや大引け準備の空白、目標足の無約定は欠損。当日引けは開示日と取引セッションが一致し、引け時刻の約定足がある場合だけ測る。分足データには板、注文優先順位、気配、約定可能サイズ、注文遅延、指数分足が含まれない。これらの値は観測された価格反応。

## 基礎集計

- 条件別に観測数、平均、中央値、標本標準偏差、正の割合、5・25・75・95%分位点。年内順位による予想差の分位では同値に平均順位を与える。過去年の利用可能期間で事後的に比較する記述集計で、当日のシグナル閾値には使わない。
- 規模・売買代金・株価は固定境界。集中日は普通株短信が100件以上の日、市場局面は前営業日TOPIX騰落の符号。初動区分は翌営業日寄りのTOPIX超過の符号で、その後だけを集計する。
- 平均追加超過の近似区間は開示日と証券コードの2方向クラスタ分散を使用。重複保有期間にまたがる異なる開示日間の相関は残り得るため、年・グループ比較や結果の確認には日付ブロックの頑健性検証が必要。
- Day 5 の追加超過について絶対値50%超を数え、絶対値上位20件の寄与を振り返れるよう保存する。外れ値を事後的に除外して平均を改善する操作は行わない。
- CSV/GZIPのSHA-256を検証して再計算する。提供元の訂正やファイルの保存期間を記録し、同一取得スナップショットで再現する。行単位の過去配信バージョンは手元のアーカイブ以降に限られる。
