# Phase 5 分析方法

```powershell
$env:PYTHONPATH = "src"
.venv/Scripts/python -m pead01.phase5
.venv/Scripts/python -m pytest -q
```

Phase 2のイベント、Phase 3のイベント日時点TOPIX区分と前営業日の貸借区分、Phase 4の財務・分足および保存済み生データを使う。入力はハッシュを記録し、検証後の再集計には `--reuse-replay` が使える。追加取得は不要。

## 価格と属性

最初の約定から5暦分後に確定する、発表前からの株価リターンと1306 ETFリターンとの差が初動。5分より後の追加超過と、初動符号を掛けた方向付き超過を保存する。継続・反転は方向付き超過の正負。ゼロはいずれにも含めない。全観測と5〜120分共通を両方掲載し、ゼロ・欠損初動は方向別集計から除く。サンプル変更で平均が変わり得るため、時間軸の解釈は共通群も参照する。

東証普通株、TOPIX構成・非構成。規模と前営業日売買代金の帯はPhase 2に従う。売買代金20日平均と標準偏差は前営業日までの20枠中15観測以上で計算。イベント後売買代金倍率は最初の5分の実績を事前ADVの65分の1（325分立会の均等配分）と比較する記述指標。前営業日価格、選択前の容量推定、残り立会分も保存する。無約定割合は観測バー数と残り立会分からの近似で、個々の欠測原因は監査表を使う。規模と初動強度の年内五分位は記述用。

市場リターンはTOPIXの5・20・60日、ボラティリティは20・60日。20日リターンの正負で上昇・下落、20日ボラをそれ以前120観測以上の拡張中央値と比較して高低を判定。全属性は前営業日付で結合する。集中日は当日開示数の記述的区分で、売買条件には使わない。

## 比較と欠損

固定初動強度帯は1、3、7%を境界とする。60分の方向付き超過の回帰に初動強度帯、連続的な絶対値、規模、流動性、業種、年、時刻、市場レジーム、方向を含める。規模と方向の交互区分も推定。対応比較は同日・同業種・同流動性帯・同方向・同時刻区分・同強度帯で、時価総額1000億円以上のイベントに最も対数売買代金が近い同未満のイベントを対応させる。同じ対照の再利用を許す。財務情報は同業種・同時刻・同規模・同方向・同強度帯の10件以上のセルで自身を除く平均を引く。

開示日・銘柄の二方向クラスタ区間と、開示日を単位として連続5日のブロック再標本化を使用する。年・四半期・銘柄別の表、各集中日区分の上位20件の符号付き寄与を保存する。回帰係数全体にHolm補正を併記する。条件付き平均の区間は多重性未調整。欠損原因は最初に当てはまる時点別の理由を付ける。収録期間外はそもそも監査対象外。休止・立会終了、株の無約定・異常、ETFの無約定・異常、初動基準欠損を分ける。生ファイルに行がない場合、実際の無約定と配信欠落の区別はできない。

## 執行

5分確定の後1・5・15暦分の指定足始値から、最初の約定から数えて60分後の観測終了価格まで。指定足欠損や休止時はスキップ。同日決済で、約定足は執行可能性の上限。容量上限は事前ADVの0.1%・1%、1件100万円、グロス1億円。現金は退出が観測され次第再利用し、同銘柄重複を回避する。日次収益は固定初期資本基準の単利、無取引営業日を含める。費用は往復5・10・20・30bp。ショートは前営業日の貸借銘柄を候補とする。値幅・板・ロット・借株の確約、空売り価格規制、逆日歩は再現していない。市場超過と現物の絶対損益を分ける。

全体、非TOPIX、事前ADV1億円以上のTOPIX、同条件かつ初動絶対値3%以上を固定比較。2026年を時系列確認に使い、2024年は11月から、2026年は11月13日まで。Phase 4で既に見た期間を含み、独立した未観測OOSではない。
