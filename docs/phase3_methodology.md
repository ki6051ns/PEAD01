# Phase 3 方法

## 時点とユニバース

Phase 2のクリーンな開示ID、JST時刻、発表前基準日と、ハッシュ検証済みのJ-Quants日足・分足・銘柄マスタを使用。TOPIX構成の判定はイベント発生日に適用される `ScaleCat` のTOPIX規模5区分。明示的な `-` は非構成、欠損は不明。休場日のみ直近営業日を参照する。前営業日適用の `Mrgn=2` は貸借銘柄の代理情報。[J-Quants 規模区分](https://jpx-jquants.com/ja/spec/eq-master/scalecategory) · [銘柄マスタ](https://jpx-jquants.com/ja/spec/eq-master)

- Aは最初の対象セッション引けの1分後にシグナル確定とし、次営業日寄りを候補にする。Cは翌営業日の実際の最初の約定を観測し、翌々営業日寄りを候補にする。Cの09:01ラベルは日足の便宜的な時刻で、初回約定が実際に成立した分は不明。日足の発注時刻はモデル上の08:59、約定時刻は寄りの09:00ラベル。
- BとMは保存済み2026年8〜10月。指数分足がないため1306の同時刻価格を市場代理とした探索。Bは14:30・14:45・15:00までに完了したバーで判定し、同日15:30の約定足がある場合のみ。2024年11月5日以降の制度を適用。取引所は15:25〜15:30に注文を受け付ける。証券会社独自締切・注文優先順位は未確認。[JPX 売買成立の方法](https://www.jpx.co.jp/equities/trading/domestic/04.html) · [J-Quants 分足仕様](https://jpx-jquants.com/ja/spec/eq-bars-minute)
- Mは最初に観測できた分足から5・15・30・60分。直前に完了した約定足でシグナルを計算し、1秒後に注文可能、次分以降5分以内に約定のあったザラバ足の始値を仮定する。発表分を除外し、昼休みや引け準備中に価格を補完しない。基準価格は同じ発表前分の株・ETF、または前日終値。分足と日次の比較には時刻とサンプルの差が含まれる。

## ポートフォリオ

- L・S・LS・LSβの固定ルール。符号、絶対2%以上、極端10%超除外、会社予想修正と同方向、時価総額1000億円と売買代金1億円以上、履歴の両端20%・10%を比較。分位は方式別の前日まで250件以上のシグナルから拡張計算。同日に出た別銘柄の決算は閾値に使わない。
- 初期資本1億円。各銘柄の等額枠は初期資本の1%。約定時刻・銘柄コード順に資金枠を割り当て、同一銘柄で保有中の新規イベントはスキップ。ショート受取金は再投資資金に回さない。未使用資金は現金、余剰資金の金利はゼロ。日次損益には非取引日を除く無イベント営業日を含む。
- 始値・ザラバ入りは当日を1日目、引け入りは次営業日を1日目とし、1・2・3・5・10・20日の終値で決済。方向別案はロング5日・ショート3日。退出時に出来高・価格が欠損するか値幅フラグがある日は5営業日の窓で再試行。未決済の評価価格は最後に観測された価格。
- 通常は前営業日売買代金の1%まで。分足は約定足売買代金の1%も上限にするため、事後バー容量を使った執行感応度である。値幅フラグ付き日のフィル拒否は保守的な事後シナリオ。理論版では入口の貸借・容量・値幅制約を外す。往復0〜50bp、片道インパクト仮定、参加率0.1%、貸株料年1%・3%も比較する。売買単位、注文板、逆日歩、空売り価格規制、配当相当額の履歴は未整備。
- LSβは直近120営業日、最低60観測の対TOPIXβを発表前営業日までで推定。各ポジションに逆方向の指数想定ヘッジを付ける。指数現物価格による損益近似で、先物の期限・ベーシス・証拠金等は未反映。日次の勝率は営業日ベースで、ESは最悪5%の営業日の平均。
- 値幅フラグの制約は日足終値での退出にも適用する。個別売買の売買代金参加率による容量は入口に適用し、出口の板とサイズは復元していない。日次グロス・ネットは、当日決済分を含む引け評価時点の観測値。

## OOS

固定3日を基準とする。過去年で学習し、直近1年を検証、次年を評価。学習は直近504日と拡張窓。学習Sharpe上位2候補を検証Sharpeで比較する。保有と決済再試行を考慮し境界の前後25営業日を評価対象から外す。継続運用系列での期間分割であり、本プロジェクトの過去フェーズで観察した期間を含む。
