```powershell
$env:PYTHONPATH = "src"
$env:OPENBLAS_NUM_THREADS = "1"
.venv/Scripts/python -m pead01.phase6_daily --output data/phase6_daily_v4

```

設定は `phase6_daily.json`、上記実行の出力は `data/phase6_daily_v4/`。`progress.json` と `status.json` に状態を保存する。経路（保有・出口）、選択、感応度別WFを保存し、同じ入力・コードで再実行すると完了済み段階を再利用する。停止はCtrl+Cまたは出力先に `pause` ファイルを作成（次のチェックポイントで停止）。再開時はそのファイルを除く。変更後の再計算は別の `--output` を指定。旧Phase 6の設定と出力に依存しない。

## 経済仮説と観測

寄りギャップは夜間の情報反映、引けまでの相対価格変化はその後の流動性・価格発見を含む。初動追随は情報の段階的伝達を仮説とする。ロング・ショートと閾値の比較で方向の非対称性を見る。日足と同時点のTOPIXを使う。分足系列はロードしない。会社予想等は配信時刻を確定できないため特徴に含めない。

寄り前および引け後開示に限定し、場中の価格区間を決算後と扱わない。引け同分はClose開始計測から外し、翌寄り以降に観測するOpen開始計測に含める。Open開始の2方式はリリース後の追加価格発見を観測する。初回寄りの成立時刻は不明なので、寄り計測も保守的にその営業日の引け後に確定扱いとし、翌営業日の寄りまたは引けで執行を試算する。日足の発注・約定時刻は板寄せラベル。対象期間末の経路は右打ち切り。

保有N日はエントリー日を0としてN営業日後の寄りまたは引け。計画保有は40日まで。指定出口に有効な価格がなければ同じ種類の次の観測可能な板寄せまで繰り越す。終端未決済は最終観測価格で評価。値幅フラグは入口・出口の保守的な不成立仮定に使う。株式分割等は既存の日足調整係数を適用し、異なる調整連鎖を接続しない。上場廃止対価・コード変更の同一性・公式停止履歴は不明で補完しない。

## 学習とWF

各候補の取引は、シグナルと入口が学習窓の始点以降、確認済み終点が境界より厳密に前にある場合だけ採点する。内部検証も同様。日界で判定し、境界当日の決済を除く。追加ブランクは学習→内部検証と内部検証→適用にそれぞれ設定する。最長窓・最大ブランクが成立する四半期から全方式同じWF。学習上位50を検証し、最低約定数に満たない場合は現金。区間日数、実際の稼働日数、最終採用取引、最終決済、除外数、候補の採否をParquetに保存する。

訓練と内側検証は個別候補の日次時価評価と費用から構成する一次採点。グロス100%上限を日次比例適用。WFは価格経路を単一資金台帳で再生し、同時刻の同銘柄注文を相殺して合算、銘柄の建玉上限と事前ADV参加率を適用する。既存建玉との重複はスキップ。20bp往復と空売り貸株料年1%は仮定。ショートは保存済み日付付き貸借区分で制限する。ブランク間の縮小共分散は各成分の共通学習日、動的配分はその直近63日で評価する。単一ブランクの動的配分は直近63学習日の縮小共分散で四半期更新する。選択・配分は適用期損益を参照しない。

感応度は片道10bpの価格悪化、往復40bp、ADV容量25%化、イベントIDで決定的に20%の注文を落とす4仮定。最高値は全方式を見た探索比較。独立OOSは未観測。入力の収録期間中に存在する市場環境や上場廃止の影響は残る。
