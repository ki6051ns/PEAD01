# Phase 4 方法

## 実行

```powershell
$env:PYTHONPATH = "src"
.venv/Scripts/python -m pead01.acquire --root data/phase4_raw --from 2024-11-14 --to 2026-07-31 minute
.venv/Scripts/python -m pead01.acquire --root data/phase4_nov --from 2026-11-01 --to 2026-11-13 minute
.venv/Scripts/python -m pead01.phase4
.venv/Scripts/python -m pytest -q
```

取得起点は2026年11月14日時点の直近2年。月次バルクが含む境界月の実データ日はカバレッジ表に記録する。J-Quantsの分足アドオンは公表上60件/分。21月次・9日次の追加ファイルと保存済み3月次を使用し、原ファイルごとの取得UTC・提供元更新時刻・SHA-256を inputs.json に保存する。ローリング期間や上書きにより将来の再取得は別スナップショットになり得る。ローカル再集計には `--reuse-paths` を使用できる。[契約別仕様](https://jpx-jquants.com/ja/spec/data-spec) · [頻度制限](https://jpx-jquants.com/ja/spec/rate-limits)

## 価格と時刻

Phase 2のクリーンな決算イベントと最初の反応セッションを使用する。時刻はJSTの分足ラベル。開示と同じ分からの取引を除外する。株価がある分のみを観測し、1306 ETFにも同じ分の観測がある場合に市場代理調整する。日足はTOPIXを用いる。場中は開示の直前5分以内の共通バー、昼休みは前引け、寄り前・引け後は分割単位を揃えた直前の日足基準で発表前価格を定義する。

初動は最初の約定足から5暦分目に利用できる株価と1306の発表前比の差。5・15・30・60・120分は初回約定足を起点に、暦分と昼休み・プレクロージングを除いた立会分を別々に測る。観測判定の直前に完了する指定バー、または指定時刻の板寄せ足を使う。前引け、後場寄り、大引け、次セッション始値、同日から数えた1・3・5・10・20日目終値を保存する。日次の追加は次セッション始値基準。Phase 2の日次パネルは開示日基準を使用した参照系列。

5分の初動に対する追加超過の逆符号、初動超過の半分以上を打ち消す変動、発表前株価との反対側に戻る変動で反転を記述する。最大順行・逆行は5分判定より後の高安、ピーク・ボトムは終値足。無約定分は補完しない。順行やピークは事後統計。発表時刻名はPhase 2由来。

## 情報特徴量

連結区分・会計基準・会計期間を照合した累計実績を保存。期間開始・終了とも前年を照合する。時系列期待値は前年同期間実績の固定モデル。会社予想差は事前FY・2Qの比較可能な予想。予想修正の比較対象は当期末、通期短信では翌期末。銘柄・対象年度末・連結区分・予想期が一致し、開示日が厳密に前の値のみ使う。同日不一致の値は欠損、資料に値がない状態も保存する。対象期間の初回は新規開示と左打ち切りを区別できない。

率の分母は金額100万円、EPSと一株配当1円以上。小さい分母でも差額と赤字・黒字転換は別途保持。進捗の分母は正の事前通期予想。会計年度内の累計値を使用し、単独四半期は分析対象外。EPS・配当は公表単位の差であり、分割前後における財務側の単位比較の限界がある。予想差や前年差を市場コンセンサスとして使用しない。

## 評価

2方向クラスタは開示日と銘柄。同一開示日をまとめ、集中日を普通株短信100件以上として層別。異なる開示日間の保有重複や共通市場代理に由来する依存は残る。分位や条件の結果は記述統計。共通集合は5〜120分すべてが揃うイベントに絞ることで、早い時間の開示や高流動性に偏り得る。

線形回帰は5分時点から60分までを同じイベント上で予測。情報モデルは営業利益の前年差と予想修正、価格モデルは初動超過と5分売買代金、統合モデルは両方。全モデルで業種・時価総額・流動性を調整し、前年以前のデータで推定。財務情報の即時利用は理論仮定。

Phase 3分解はA、C、B1445、M15をAの建日から数えて5日目の終値に統一し、価格と方向の置換順を平均する。各方式の利用可能集合と共通集合の差も測る。早い価格で後のシグナルを使う項は寄与の反実仮想。板、約定順位、証券会社締切や約定可能数量は未検証。
