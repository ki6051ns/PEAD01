# Phase 2 方法

## 観測点

Phase 1の保存済みParquetを監査の基準とする。Phase 2の日次 Day N は翌東証営業日始値を Day 1 の起点とし、その日を含む N 日目の終値まで測る。全時間軸が揃う共通集合を併記する。初動はPhase 1の発表前基準価格から翌営業日始値までのTOPIX超過。日中・寄り前開示では翌営業日前までの場中変動も含む。

初動の符号は翌営業日の始値が観測された時点で判明する。主分析で同じ始値を基準にすることには同値約定の先読みがあるため、次の営業日始値から同じ終点までのDay 3以降も測る。この感応度分析も約定の保証を与えない。予想修正は前日までの同じ対象年度・連結区分の会社予想と当該短信の差を使う。

回帰では初動符号に加え初動超過リターンの大きさも調整する。推定は条件付きの関連を表す。

## 対照と条件

対象と同じ起点日・終点日を使用し、開示日前の直近営業日時点の東証普通株・33業種を照合。発表日前営業日から起点日の09:00より前に短信または単独業績予想修正を発表した銘柄を対照候補から除く。起点後の開示は候補選定に使わない。対照群の選択には起点当日の価格・将来のリターンを使わない。業種基準はこの候補の等ウェイト。

マッチは時価総額と当日売買代金の固定帯が両方同じ候補から、両変数の自然対数距離の二乗和が最小の1社。銘柄コード順で同点を解消。復元抽出を許す。時価総額の境界は300億・1000億・5000億・1兆円、売買代金の境界は1000万・1億・10億円。終点の欠損で対照を選び直さない。分解表では全調整値が揃うイベント集合上で差を比較する。

初動・上方修正率・上方修正額の分位は全期間内の平均順位を用いた記述統計。将来の取引閾値に使わない。Momentumは属性基準日を終点とする60営業日前比の調整済価格リターン。60営業日離れた価格が利用できる場合に限る。マッチ済みイベントのDay 5について、初動符号・修正方向とその交互作用、規模・流動性・Momentum・年・業種・決算期・発表時刻を同時に比較し、会社予想比の営業利益差があるサンプルではその符号も含める。Valueの時点整合データは使用しない。

## 推定と分足

開示日・銘柄の2方向クラスタ分散で平均と回帰係数の近似区間を計算する。共通対照の再利用・異なる開示日の保有重複には追加の依存性が残る。絶対値の上位20件の寄与を保存する。決算集中日は開示日100件以上の東証普通株短信がある日。

分足はPhase 1で確定した観測を使用し、開示日時と最初の約定足の開始時刻の差を暦分で記録する。1分足による時間分解能の制約がある。全観測、60分まで全点が揃う集合、当日引けも揃う集合を発表時刻区分で併記する。
